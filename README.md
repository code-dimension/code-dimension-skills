# AI Skills Repository

This repository provides a collection of specialized instructions and architectural rules (AI Skills) designed to enhance the precision and consistency of AI coding assistants.

## 🚀 Available Skills

- **[angular-arch](skills/angular-arch/SKILL.md):** Rules for structuring Angular workspaces into core, features, and shared directories using modern patterns (Signals, `inject()`).
- **[daisy-ui-v5](skills/daisy-ui-v5/SKILL.md):** Best practices and conventions for integrating DaisyUI v5 into web projects.

---

## 🛠️ Installation

You can install these skills directly into your project using the [skills.sh](https://github.com/code-dimension/skills-cli) CLI.

### Install skills:

```bash
npx skills add https://github.com/code-dimension/code-dimension-skills
```
